## Projekt

BG-RehaManager Südwest ist eine webbasierte Arbeits- und Orientierungshilfe zur strukturierten Darstellung von Einrichtungen und Angeboten aus den Bereichen medizinische Rehabilitation, berufliche Teilhabe, soziale Teilhabe, Beratung und ergänzende Reha-Dienstleistungen im südwestdeutschen Raum.

Die Anwendung umfasst unter anderem eine eigenständig entwickelte Auswahl-, Kategorisierungs- und Suchlogik sowie einen kuratierten und strukturierten Datenbestand.
