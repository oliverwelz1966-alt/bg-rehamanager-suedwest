Installation als App / Desktop-Icon

Microsoft Edge: Menü (…) → Apps → „Diese Website als App installieren“ → Installieren. Danach kann das Symbol auf dem Desktop bzw. in der Taskleiste verwendet werden.

Google Chrome: Menü (…) → Speichern und teilen → „Verknüpfung erstellen“.

Version 4.5 ändert die bestehende Zugangssicherung nicht; sie erweitert die Anwendung hinter dem bestehenden Zugang.
